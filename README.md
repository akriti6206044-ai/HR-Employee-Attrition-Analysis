# HR-Employee-Attrition-Analysis
An end-to-end HR Employee Attrition Analysis project using Python, SQL, Excel, and Power BI to analyze employee turnover, identify key factors affecting employee retention, explore department-wise attrition, and generate actionable business insights through data analysis and interactive dashboards.

# HR Employee Attrition Analysis Project

## 1. Introduction

HR Employee Attrition Analysis is a Data Analytics project that helps organizations understand why employees leave their jobs.

Employee attrition is one of the major challenges faced by companies. High employee turnover increases recruitment costs, training expenses, and workload.

In this project, I will analyze employee data using Python, SQL, Excel, and Power BI to identify the main factors responsible for employee attrition.

## 2. Problem Statement

Companies face difficulties retaining employees. They need to understand which departments have high employee turnover and what factors influence employees to leave.

This project aims to solve this problem through data analysis and visualization.

## 3. Project Objectives

1. Calculate the total number of employees.
2. Calculate the employee attrition rate.
3. Analyze department-wise attrition.
4. Analyze gender-wise attrition.
5. Identify age groups with high attrition.
6. Analyze salary and employee satisfaction.
7. Understand the impact of overtime on attrition.
8. Provide recommendations to improve employee retention.

## 4. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Microsoft Excel
- Power BI

## 5. Expected Outcome

The project will help identify employee turnover patterns, understand employee behavior, and provide useful business insights to improve employee retention.
